The three Instrument Serif / JetBrains Mono WOFF2 files are compressed packages of the matching existing `public/fonts/*.ttf` files. FontTools 4.61.1 performed the conversion without subsetting; character maps, glyph order and horizontal metrics were compared after reopening each result. Original TTF files and their SIL Open Font Licenses in `public/fonts/licenses/` remain unchanged. No family, weight, glyph coverage or design change was introduced.

The source files total 238,664 bytes; WOFF2 copies total 89,540 bytes. Network savings differ because the server also compresses TTF responses. Font conversion is a development-only operation; no Python dependency was added to the application. See `docs/redesign/p7-font-conversion.json` for individual source hashes and checks.

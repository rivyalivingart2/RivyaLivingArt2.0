# Whole-site cinematic direction and execution checklist

Owner scope: 16 October 2026 CRAFT master prompt, implemented locally on codex/cinematic-sections. This extends the earlier homepage work to the actual shared public templates, dynamic content, Studio access pages and admitted administrative workspaces. It does not authorize a release.

The design direction is a continuous charcoal/navy canvas, ivory editorial typography, restrained gold accents and original Rivya media. One diffused cursor light eases toward the mouse; slow ambient lighting carries the same palette between sections. Public storytelling receives stronger media and viewport compositions. Accurate product photography, reading, forms, print and administration keep stable content surfaces. No WebGL or new motion dependency is needed: reuse installed GSAP with progressive, optional enhancements.

## Execution checklist

1. Audit every route, shared template, optional layout and existing media. Capture before views and a read-only preservation snapshot.
2. Establish shared gradient, lighting, duration, easing and colour tokens without changing the logo or palette.
3. Connect one reusable cursor/ambient boundary per public page, Studio workspace and access page; add a persistent pause preference and static fallbacks.
4. Retain and verify fullscreen hero and Resin in Motion video parallax; apply seamless home chapter composition.
5. Update all public template families: collections, product journeys, narrative pages, editorial archives/details, gallery, forms, FAQs and policies.
6. Apply artistic background continuity to Studio entry and saved presentation views.
7. Apply restrained surfaces to all admitted Studio workspaces, retaining natural-height productivity layouts.
8. Check desktop, tablet and mobile at 1920, 1440, 1200, 992, 768, 512, 390 and 320 pixels, plus keyboard, reduced motion, print and media fallbacks.
9. Fix discovered regressions; verify optional motion cleanup, loading discipline and unchanged data/content.
10. Save a route audit, component research, before/after gallery, technical results and a 20-item honest compliance report with a continuation checkpoint.

## Deliberate exceptions

No fixed viewport height on lists, forms, FAQs, long reading or administrative tables. No moving overlay over accurate product imagery or focused inputs. No cursor simulation on touch; static gradients on reduced-motion, data-saving or modest-device profiles. No animation inside print output or the isolated public preview iframe wrapper. Existing media credits, concept/fictional disclosures and crops are preserved. No new stock imagery, external scripts, telemetry, publication, database write or package installation.

## Verification boundary

Browser checks will be local and use the isolated QA database. Native screen-reader, physical-device, independent-language, field performance and genuine customer evidence cannot be inferred from these checks. Final reports will distinguish source coverage, exercised runtime states and those external acceptance limits.

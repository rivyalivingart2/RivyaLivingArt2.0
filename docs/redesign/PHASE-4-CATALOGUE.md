## P4.3 — URL discovery contract

|---|---|
| q | Up to 100 characters; normalized case/spacing; all search terms match against ID/name/form/category/material |

No per-keystroke history churn, localStorage or search persistence outside the URL. Existing native scroll and responsive grid remain; compact toolbar fields stack at 540px. Back/Forward scroll restoration and screen-reader behavior are prepared for Phase 11, not claimed verified.

## P4.4 — product, gallery, care and related pieces

- Public projection reads visible published product JSON and published media concurrently, then validates identity, shape and positive version. It whitelists public properties instead of spreading arbitrary stored JSON into client props.
- A missing/invalid/unassociated primary published media record holds that product out of discovery and customization. Optional scene/gallery records are omitted individually when unavailable. Slug collisions are not emitted twice. Database failures remain service failures and never cause fixture publication.
- A public media record must belong to that product ID. No URL is guessed and another product's image is never substituted. For newly authored IDs, approved associated media must first exist; wider authoring support is a Phase 7 dependency.
- Detail breadcrumbs lead to the correct collection. Specifications use the exact published product. Care guidance distinguishes furniture, preservation and personal objects without unsupported heat/food/skin/UV guarantees.
- Related products prefer the same category within the same journey, omit the current product and give a collection recovery path when no related product exists.
- Galleries reset by product ID/revision, retain thumbnail focal positions, safely handle an empty source list, bound their active index and cancel interrupted gestures. Horizontal swipe requires dominant horizontal movement, preserving ordinary vertical scroll.
- Native previous/next, thumbnail labels, image count and zoom remain. PublicImage handles missing sources and failed images with truthful status; retry remains available when an actual source exists. A no-JavaScript gallery supplies direct links to its published images.

## Decisions resolved

- Keep current public canonical routes. The complete shop composition belongs in current search/discovery, retaining existing legacy alias behavior. Dynamic product/category/article/portfolio identities require exact lookup; absent old identities never select an unrelated record.
- Studio admits one module segment. Detail and create views use validated record/create query state. The current content and inquiry editors already read record selection; products and new destinations need explicit adapters. Printing is a view of the authorized saved order, never an old public receipt or a new customer message.
- Existing staff/business/navigation authority and current API authorization remain. Analytics means existing scoped aggregates, not new tracking. Exports use the current managed export service and retention/privacy handling. No export is executed as part of source reconciliation.
- Import, scraper and ingestion-dependent Catalog Fill remain source-only/conditional with no active ingestion action. Signup/reset/email recovery are not ported from old authentication.
- All 74 structural slots are specified, including ten process and four material slots. Slot count is not evidence of ten current business steps or four approved materials. Bind current exact text by meaning; unbound slots stay absent publicly and explained in Studio.
- Home Furniture and Rooms remain separately disabled by default. Workshop/printing facts require genuine supported offerings. Newly created Portfolio concepts and Testimonial samples follow the owner's 9 October classification decision everywhere they appear.
- Landing blocks are typed, bounded and inert. Media, CTA, product and editorial references resolve current published identities. No old executable HTML, Prisma models or source data is imported.
- Current cookies/storage do not justify copying an unrelated consent system. A preferences surface must represent actual optional storage. Existing locale/session/inquiry/saved-piece behavior stays intact.
- Preserve current full-screen sections and subject crops. Copy the old obsidian/ocean/sapphire typography and surface hierarchy; keep focus, touch size, reserved media dimensions and static reduced-motion content as documented adaptations.

## Documented adaptations

Control boundaries use #78828c instead of the old #6f7680 to clear 3:1 against the nested ocean surface. The small Studio wordmark uses the interface face after repeated local screenshots showed that the display face was present in the DOM but did not paint at that size; a temporary system-font diagnostic rendered it correctly. The display face remains for public editorial headings. This is an observed local rendering fix, not a claim about physical devices.

The mobile page finder becomes an icon with its accessible name intact. Only its visual caption is hidden. Current account role, sign-in renewal and sign-out remain reachable.

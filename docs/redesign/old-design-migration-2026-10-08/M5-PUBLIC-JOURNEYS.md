- The current shop/category/three-journey layouts, filters, stable product addresses, saved pieces and commission forms remain the functional base. Additive FAQs appear alongside the unchanged original answers. New records use the existing content, revision, permission and publication services. Unknown or draft-only records return 404; FAQ loading is confined to the index so it cannot prematurely stream a 200 response for an unavailable answer.

Genuine entries require source, publication permission, reviewer and a valid approval date. Private evidence is stripped from public projections. These fields support recorded evidence, not an automated assertion that a human review occurred.

Recent mode uses saved publication timestamps; older records without a timestamp use a stable identity tie-break.
- Independent media usages preserve existing associations and crops. New wide ratios, keyboard gallery, deliberate video playback, native controls and still-image fallback reuse the approved M4 media. Optional WhatsApp links resolve the current business number and only open a conversation. New assets, Drive delivery and the 480 editorial entries belong to M9.
- Policies, Imprint contact binding, aliases, private previews, maintenance/error/410 states and indexing boundaries reuse the existing tested services. No approved policy or business values were rewritten.

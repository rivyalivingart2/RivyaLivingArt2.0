# Cinematic section layout specimens

Read-only static rendering of the actual HomepageDocument components and styles. These specimens use public source fixtures, never database writes or publication.

- all: all optional composition slots, explicitly fictional/concept examples and a long disclosure caption
- classic: existing non-reference composition
- editorial: saved editorial hero image/caption
- empty: missing local products/media, preserving fallback behavior

Build with Node 22: `node experiments/cinematic-sections/build.mjs` while the guarded isolated application is available at http://127.0.0.1:4199. Serve with `node experiments/cinematic-sections/serve.mjs` on loopback port 4185.

The specimens intentionally do not hydrate. Use the actual local application for video playback, navigation, keyboard and mutation workflows. These files are layout evidence, not published content. Output and screenshots are ignored by Git.

The /review gallery is generated by build-review.mjs from captured local images. Evidence routes serve only PNG/JPEG screenshots from the dedicated task evidence directory. No private JSON, credentials or database snapshots are exposed.

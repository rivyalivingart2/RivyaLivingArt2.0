# Phase 1 preview direction contract

Status: proposed composition for owner review, not production approval. The seven-phase plan and Phase 1 are authorized; Phase 2 is not.

The original user request is a complete new public/Studio design with modern parallax, scroll animation and smooth scrolling, retaining logo, main colours, all content and functionality. This Phase 1 delivers four representative responsive specimens and preservation/coverage documentation only. No integration or reusable production motion framework is authorized yet.

## Visual world
Contemporary material gallery. Existing resin furniture imagery carries the public identity. Instrument Serif is the existing display face; Inter is the existing functional/readable face. Use exact obsidian #080a0e, deep ocean #08283a, sapphire #164e6b, champagne #b89b63, ivory #f4f1e9 and existing supporting colours. Original logo bytes are displayed without recolouring or filters on an ivory support. A proposed ivory Journal reading surface and Studio workspace bring clarity using an existing brand colour, with dark framing retained. Owner can judge that balance in the previews.

## First viewports and composition
- Home (Experience/Persuade): large original title left, decisive River Channel room visualization right; a coherent opening rather than many animated fragments. Continued asymmetric selected-work gallery, material film, Journal and invitation. Representative subset only; all 18 current homepage slots mapped separately.
- Product (Experience/Operate): dominant product gallery left, deep-ocean details/inquiry panel right; exact River Channel story and original price-on-request wording. Material/disclosure/ordering notes remain visible.
- Journal (Read): title and introduction beside an existing image, followed by quiet ivory reading surface, anchored contents and the complete source article. No animated paragraph reading.
- Studio (Operate): dark branded navigation, ivory working surface, stage tabs, searchable order list and contextual brief panel. Eight stages with the existing fictional examples. No fabricated dates, events, customers or contact data.

## Interaction specimen and scope
Plain HTML/CSS/JS, isolated localhost allowlist server, no production APIs or browser persistence. Preview switching, gallery controls, browser-only saved state, article anchors, video play/pause, stage selection, local filtering and detail tabs can be explored. Operational actions open an explicit prototype notice. Public reference links may open the current site read-only in a new tab.

Only a light opening-image movement and native smooth anchor navigation are demonstrated. Both respect reduced motion. Full parallax/scroll choreography and the runtime framework are Phase 2 onward. Selected assets are already approved project derivatives; material-film bytes match a previously recorded Drive provenance receipt. New Drive selection, generation, upload and Studio asset publication are not Phase 1 work.

## Quality and limitations
Target previews: desktop 1440×1000 and mobile browser emulation 390×844. Keep content readable on initial render, control focus visible, true image identity and captions intact. No private IDs, contacts, production operations or real customer copies in the prototype. Existing source copy is checked for exact identity for River Channel and DB001. Real native/device/reader/field acceptance remains separate; this is not production QA.
